Hard house is the UK's high-energy club sound: fast, relentless, built on **offbeat bass stabs**, **hoovers** and huge **drum-roll drops**.

## Where it comes from

Hard house emerged in the **UK in the early 1990s**, closely tied to the **Trade** club in London. Its roots include Belgian and German techno, disco-sample house and early trance. Tony De Vit is often called its "godfather"; labels and nights like Tidy, Sundissential and Frantic defined the sound. It overlaps with **hard NRG** (faster, more trance) and with **bounce / donk** (lesson 17).

## The fingerprint

| Element | Rule |
|---|---|
| Tempo | about **135–165 BPM**, typically around **150** |
| Kick | four on the floor, hard, distorted, short tail |
| Bass | **offbeat bass stabs** — short, punchy, often distorted |
| Leads | **hoovers**, stabs, horns; riffs of 1–2 bars |
| Breakdown | often a **long, sharp string note** held to build suspense |
| Drops | usually introduced by a **drum roll** |
| Hats | open hat on the offbeat, driving 16ths |

## The offbeat bass stab

Not a smooth bassline — a **stab**: a short, bright, aggressive hit on each offbeat, often a chord or an octave stack rather than a single note.

<Strudel title="offbeat bass stab" code={`
  setcpm(150/4)
  stab: n("<0 0 5 4>").struct("[~ x]*4")
    .add(n("0,7"))                       // root + octave
    .scale("A1:minor")
    .s("sawtooth").lpf(1400).lpq(5)
    .decay(0.1).sustain(0).distort(1.5).gain(0.7)
  kick: s("bd*4").bank("RolandTR909").distort(1.5).decay(0.3).gain(0.9)
  hats: s("[~ oh]*4, hh*16").bank("RolandTR909").gain(0.35)
`} />

## The suspense string

A single high note held for the whole breakdown, maybe slowly opening, is a hard house signature. It is pure tension (lesson 14): it never resolves until the drop. Two details make it work in Strudel: `.slow(8)` turns it into **one** note 8 bars long, and the filter opens through a long filter envelope (`lpattack`), because a pattern like `saw` on `lpf` is only read when a note starts.

<Strudel title="long sharp string note" code={`
  setcpm(150/4)
  note("e5").slow(8)                       // ONE note lasting 8 bars
    .s("supersaw").unison(5).detune(0.25)
    .attack(1.5).sustain(1).release(2)
    .hpf(400).lpf(1500).lpenv(2).lpattack(12).lpsustain(1)  // filter opens over ~12 s
    .room(0.8).roomsize(8).gain(0.25)
`} />

## The template

A full 112-bar hard house track (≈ 3 min at 150 BPM): hoover riff, offbeat stabs, a suspense breakdown and a drum-roll drop.

<Strudel title="hard house track template" code={`
  setcpm(150/4)
  const prog = "<0 0 5 4>"

  const kick   = s("bd*4").bank("RolandTR909").distort(1.5).decay(0.3).gain(0.9)
    .duckorbit(2).duckdepth(0.5).duckattack(0.12)
  const hats   = s("[~ oh]*4, hh*16").bank("RolandTR909").gain(0.35)
  const clap   = s("~ cp ~ cp").bank("RolandTR909").gain(0.7)
  const stab   = n(prog).struct("[~ x]*4").add(n("0,7")).scale("A1:minor")
    .s("sawtooth").lpf(1400).lpq(5).decay(0.1).sustain(0).distort(1.5).gain(0.65)
  const hoover = note("<[a2 ~ ~ a2 ~ ~ g2 ~] [c3 ~ ~ a2 ~ ~ e2 ~]>")
    .add(note("0,12,-12")).s("supersaw").unison(5).detune(0.6)
    .penv(-12).pattack(0.1).phaser(4).lpf(3000).distort(1)
    .decay(0.4).sustain(0.6).release(0.1).gain(0.3).orbit(2)
  const string = note("e5").slow(16).s("supersaw").unison(5).detune(0.25)
    .attack(1.5).sustain(1).release(2).hpf(400)
    .lpf(1500).lpenv(2).lpattack(20).lpsustain(1)
    .room(0.8).roomsize(8).gain(0.22).orbit(3)
  const roll   = s("sd*<4 4 8 8 16 16 32 32>").bank("RolandTR909")
    .gain(saw.range(0.3, 1).slow(8)).speed(saw.range(1, 1.6).slow(8))

  arrange(
    [16, stack(kick, hats)],                                       // intro
    [16, stack(kick, hats, clap, stab)],                           // stabs in
    [16, stack(kick, hats, clap, stab, hoover)],                   // hoover riff
    [16, stack(string)],                                           // suspense breakdown
    [8,  stack(string, roll).mask("<1!7 [1 1 1 0]>")],              // drum roll
    [24, stack(kick, hats, clap, stab, hoover)],                   // drop
    [16, stack(kick, hats, stab)]                                  // outro
  )
`} />

## House vs bounce vs hard house

| | House | Bounce / donk | Hard house |
|---|---|---|---|
| Tempo | 115–130 | ~140–150 | 135–165, ~150 |
| Kick | clean, round | punchy, distorted | hard, distorted, short |
| Offbeat | open hat | **donk** (bass) | **bass stabs** |
| Top line | chords, piano, vocals | catchy sing-along hook | hoover riffs, stabs, horns |
| Breakdown | chords + pad | the hook alone | long suspense string |
| Into the drop | gentle build | roll + riser | **drum roll** |
